# 蒙特卡洛竞技场

> 产品命名决定 · 2026-10-03 · dev-ai-lottery 第一阶段完成后确立

## 名称

- **中文**：蒙特卡洛竞技场
- **英文**：Monte Carlo Arena
- **简写**：MCA

## 描述

蒙特卡洛竞技场（MCA）是一个运行在闲置 Android 手机上的双色球（SSQ）多策略竞赛：六位纯 JVM 策略、三位 LLM 人格选手与纯随机对照组同场竞技、每期对账，诚实回答「任何算法（含端侧 LLM）能否打赢纯随机」。定位为诚实实验 + 统计娱乐，不是预测或投资工具。

「蒙特卡洛」一词承载双重身份：赌城（娱乐性）与随机模拟方法（科学性）。程序的零分布与 p 值正是用蒙特卡洛模拟算出来的——名字不只在玩梗，它直接命名了程序里真实运行的核心算法，故科技感与机制同源。

本文档落盘后，此程序在一切文档与对话中统一称为「蒙特卡洛竞技场 / MCA」，取代此前「Scrapbook4Android 彩票工程」等临时指称。
